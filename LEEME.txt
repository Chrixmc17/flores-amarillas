RECORRIDO

3. dedicatoria.html
   Mensajes, versos, detalle final y firma.

PARA GITHUB PAGES

1. Crea un repositorio.
2. Sube todos los archivos manteniendo las carpetas.
3. index.html debe permanecer en la raíz.
4. Ve a Settings > Pages.
5. En Branch selecciona main y /root.
6. Guarda y espera a que GitHub genere el enlace.
